Backend-сервис для платформы размещения объявлений

Общая информация
Проект представляет собой REST API сервис для платформы размещения объявлений с поддержкой пользователей, объявлений, комментариев и загрузки изображений.
Система обеспечивает регистрацию и авторизацию пользователей, управление объявлениями, добавление комментариев и хранение изображений на файловой системе.

Быстрый запуск проекта
Проект полностью контейнеризирован и может быть запущен одной командой.
Требования:
- Docker
- Docker Compose
1. Запуск проекта
В корне проекта выполнить:
docker-compose up --build
2. При запуске:
PostgreSQL
- создаётся база ads
- создаётся пользователь ads_user
- база доступна по порту 5432
Backend
- приложение собирается внутри Docker (multi-stage build)
- запускается Spring Boot
- подключается к базе данных
3. Миграции базы данных
Структура базы создаётся автоматически через Liquibase:
users, ads, comments, foreign keys
Расположение миграций:
src/main/resources/db/changelog/
4. Переменные окружения
Для подключения к базе используются переменные окружения:
DB_USERNAME
DB_PASSWORD
SPRING_DATASOURCE_URL
По умолчанию используются значения из docker-compose.yml.
5. Доступ к приложению
После запуска:
http://localhost:8080
6. Остановка проекта
docker-compose down
Для удаления данных БД:
docker-compose down -v

Архитектура приложения
Проект построен по слоистой архитектуре:
- Controller слой — обработка HTTP-запросов
- Service слой — бизнес-логика
- Repository слой — доступ к данным
- DTO слой — обмен данными между клиентом и сервером
- Mapper слой — преобразование Entity ↔ DTO

Функциональность пользователей
- Регистрация нового пользователя
- Авторизация
- Получение информации о текущем пользователе
- Обновление профиля пользователя
- Обновление аватара пользователя
- Изменение пароля пользователя

Функциональность объявлений
- Создание объявления
- Редактирование объявления
- Удаление объявления
- Получение списка всех объявлений
- Получение объявления по идентификатору
- Обновление изображения объявления

Функциональность комментариев
- Добавление комментариев к объявлениям
- Редактирование комментариев
- Удаление комментариев
- Получение списка комментариев объявления

Работа с файлами
Изображения сохраняются в локальную файловую систему сервера.
Базовый путь хранения:
images/
Структура хранения:
images/
├── users/{userId}/
└── ads/{adId}/
Доступ к изображениям:
GET /images/{path}

Безопасность
В проекте используется Spring Security.
Реализованы:
- аутентификация пользователей
- защита эндпоинтов
- разграничение доступа на основе ролей
- проверка прав доступа через аннотацию @PreAuthorize

Основные REST endpoints
- Пользователи
   POST /register
   POST /login
   GET /users/me
   PATCH /users/me
   PATCH /users/me/image
- Объявления
   GET /ads
   POST /ads
   GET /ads/{id}
   PATCH /ads/{id}
   DELETE /ads/{id}
   PATCH /ads/{id}/image
- Комментарии
   GET /ads/{id}/comments
   POST /ads/{id}/comments
   PATCH /ads/{adId}/comments/{commentId}
   DELETE /ads/{adId}/comments/{commentId}

Особенности реализации
- Использование DTO для внешнего API
- MapStruct для автоматического маппинга сущностей
- Хранение изображений вне базы данных
- Централизованная обработка файлов через сервис
- Использование Spring Security для защиты API
- Контроль доступа через аннотации @PreAuthorize
- Управление схемой БД через Liquibase

Заключение
Проект реализует серверную часть платформы размещения объявлений с полной поддержкой пользовательского взаимодействия, управления контентом и безопасного доступа к данным.
